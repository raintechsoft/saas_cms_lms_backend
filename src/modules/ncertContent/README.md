# NCERT Content (v1)

Flat study resources keyed by class, subject, and chapter name.

## Ownership

`createdById` owns drafts (Lesson Planning pattern). Teachers need the create toggle; only admin/staff publish or archive.

## Publish rules

Requires title, `resourceUrl` (link or uploaded file URL), and class. Portals only see **PUBLISHED** for the student's class.

## Resource types

- `LINK` — external URL
- `FILE` — uploaded via `POST /ncert-content/upload`, then saved on the resource
