# Lesson Planning (v1)

Teacher lesson plans by subject/class. No student delivery yet.

## Ownership

`LessonPlan.createdById` owns the plan (Question Bank draft pattern).

| Actor | Create | Edit own DRAFT | Publish / archive |
|-------|--------|----------------|-------------------|
| Teacher (toggle on) | Yes | Yes | No |
| Admin / Staff | Yes | Yes (any) | Yes |

Settings: `TenantLessonPlanningSetting.allowTeachersToCreateLessonPlans`
